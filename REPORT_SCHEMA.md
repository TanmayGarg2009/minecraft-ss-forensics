# Forensic Report Schema Specification

This document details the JSON schema specification for reports generated by **Minecraft SS Forensics** (v2.1.0).

---

## 1. Schema Envelope Overview

Reports are structured into an envelope with metadata, an integrity seal, and the complete forensic payload:

```json
{
  "SchemaVersion": "2.1.0",
  "Metadata": {
    "ScanId": "f7d3a8b2-1c4e-4e6f-9a0d-3b5e8c1a7d9f",
    "GeneratedAtUtc": "2026-10-30T18:00:00.0000000Z",
    "ScannerVersion": "2.1.0",
    "Environment": {
      "OperatingSystem": "Microsoft Windows 11 Pro 10.0.22631",
      "Architecture": "X64",
      "IsElevated": true,
      "UserName": "Player"
    },
    "IntegritySeal": {
      "Algorithm": "SHA256-CANONICAL-V2",
      "CanonicalDigest": "a3b4c5d6e7f80123456789abcdef...",
      "Signature": "a3b4c5d6e7f80123456789abcdef..."
    }
  },
  "Payload": {
    "Summary": {
      "OverallVerdict": "VIOLATION_CONFIRMED",
      "ProhibitedPossessionCount": 1,
      "ProhibitedExecutionCount": 0,
      "NeedsReviewCount": 0,
      "TotalVerifiedMods": 12,
      "TotalDiscoveredMods": 13,
      "DurationMs": 2450
    },
    "Findings": [ ... ],
    "DiscoveredMods": [ ... ],
    "ProcessTelemetry": [ ... ],
    "HistoricalEvidence": { ... },
    "SystemServices": [ ... ],
    "UsbDevices": [ ... ],
    "BrowserAudit": { ... },
    "AuditTrail": [ ... ]
  }
}
```

## 2. Field Specifications

### 2.1 `Metadata`
- `ScanId` (UUID): Unique globally unique identifier generated per scan execution.
- `GeneratedAtUtc` (ISO 8601): Exact UTC timestamp of scan completion (`yyyy-MM-ddTHH:mm:ss.fffffffZ`).
- `ScannerVersion` (string): Application semantic version (`2.1.0`).
- `Environment` (object): Host OS build, architecture, and privilege level.
- `IntegritySeal` (object): Cryptographic proof container.

### 2.2 `Payload.Summary`
- `OverallVerdict` (enum): `CLEAN`, `SUSPICIOUS`, `VIOLATION_CONFIRMED`, `ERROR`.
- `ProhibitedPossessionCount` (int): Number of items violating possession policies.
- `ProhibitedExecutionCount` (int): Number of items with verified execution traces.
- `NeedsReviewCount` (int): Number of unverified or modified items requiring manual staff review.
- `TotalVerifiedMods` (int): Count of mods matching official Modrinth/CurseForge releases.
- `TotalDiscoveredMods` (int): Total count of JAR files evaluated across all Minecraft instances.

### 2.3 `Payload.Findings` (array of objects)
Each finding represents an evidentiary conclusion:
- `FindingId` (UUID): Unique finding identifier.
- `RuleId` (string): Specific policy rule triggered (`RULE-METEOR`).
- `ArtifactName` (string): Filename or module name.
- `FilePath` (string): Absolute disk path on target host.
- `FileSha256` (string): Cryptographic SHA-256 hash.
- `SoftwareState` (enum): Classified state among the 8 software states.
- `EvidenceState` (enum): Classified evidentiary status among the 9 states.
- `Confidence` (object): `Score` (`0.00 - 1.00`), `Level` (`High`, `Medium`, `Low`, `Corroborated`).
- `TelemetrySources` (array of strings): Sources confirming the finding (`Filesystem`, `Prefetch`, `Bytecode`).
- `PolicyDecision` (enum): `PROHIBITED_POSSESSION`, `PROHIBITED_EXECUTION`, `ALLOWED`, `NEEDS_REVIEW`.
- `Details` (string): Human-readable explanatory forensic notes.

## 3. Integrity Seal Verification Algorithm (`SHA256-CANONICAL-V2`)

To verify report authenticity:
1. Extract `Payload` and serialize it into a canonical string:
   - Order all JSON object keys ordinally (case-sensitive ASCII).
   - Format numbers without trailing zeroes or exponential notation.
   - Format timestamps in invariant UTC ISO 8601 with 7-digit microsecond precision.
   - Strip all indentation and extra whitespace.
2. Compute SHA-256 over UTF-8 bytes of canonical payload string:
   $$\text{ComputedDigest} = \text{SHA256}(\text{CanonicalPayload})$$
3. Compare `ComputedDigest` against `Metadata.IntegritySeal.CanonicalDigest` using constant-time comparison (`FixedTimeEquals`).
